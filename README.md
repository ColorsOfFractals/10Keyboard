# 10Keyboard

A retro cellphone-inspired text editor for Windows.

Type like it's 2002, but with your physical numpad.

## Features

- Classic multi-tap typing
- T9 predictive text
- Physical numpad and clickable digital keypad
- Five retro themes
- Text file editing and clipboard copying
- Custom pixel-art Windows icon
- Expandable word dictionary

## Running

Requires Python 3 with Tkinter.

Run: python 10Keyboard.py

## Controls

7 ABC    8 DEF    9 GHI
4 JKL    5 MNO    6 PQRS
1 TUV    2 WXYZ   3 Punctuation

0 = Space
Decimal = Delete
Plus = Copy all text
Divide = Switch typing mode
Multiply = Toggle case
